# MDP Landing Page

Mustafa Development Projects — static landing page.

## Deploy to Cloudflare Pages

1. Log into Cloudflare.
2. Go to **Workers & Pages** / **Compute**.
3. Choose **Create application** → **Pages** → **Direct Upload**.
4. Upload the contents of this folder, or upload `mdp-landing-page.zip`.
5. Deploy.
6. Cloudflare will give you a `*.pages.dev` URL.

## Before launch

Open `index.html` and replace:

`contact@mdpllc.com`

with the real MDP business email.

The page is intentionally built with no paid libraries, frameworks, backend, database, or hosting dependency.
